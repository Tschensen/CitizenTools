OCR runtime / Herkunft und zugehörige Quellen

Unmodified MSYS2 UCRT64 packages: Tesseract 5.5.3, Leptonica 1.87.0,
with English and German language data. Original license documents are
listed separately by component. Versions below include MSYS2 package revisions.

Exact package URLs, hashes, file ownership and corresponding source archive
names are recorded in packaging/ocr-lock.json (also licenses/ocr-lock.json
in the Windows package). Sources, patches and matching build recipes are
provided in CitizenTools-Solo-OCR-Sources.zip next to the Windows downloads:
https://github.com/Tschensen/CitizenTools/releases
See docs/OCR-SOURCES.md for rebuild instructions. No original OCR code was
modified. Only required executable/DLL files and eng/deu models are bundled.
Windows system DLLs are not redistributed in this OCR directory.

GPL/LGPL libraries retain their terms; the sources ZIP supplements, rather
than replaces, CitizenTools-Solo-Source.zip. JBIG-KIT source headers allow
GPL version 2 or later; GPLv3 is used for this combination. GCC libraries
include the GCC Runtime Library Exception. The dynamically loaded DLLs can
be replaced by the user; no signature or integrity checks run in the app.
